# Music

Odeum's soundtrack packs are written as Python scripts in `tools/odeum/drafts/` (see the README
there) and exported into `mods/Odeum/packs/<pack>/music/`.

- `ORIGINAL.md`: analysis of the original Balatro theme (tempo, meter, chords, form) that every pack re-arranges.
- `BRIEF.md`: what each pack sounds like and the rules every pack follows.
- `soundfonts/` (local only): MuseScore_General.sf2.
- `reference/` (local only): renders and excerpts of the original, for comparison.
- `<pack>/sketches/` (local only): listening renders.

## One song, five versions
The game plays all five at once and crossfades between them, so they share tempo, chords and length.

| File | Version heard |
|---|---|
| `music1.ogg` | main (blinds) |
| `music2.ogg` | Tarot, Spectral, Standard and Buffoon packs |
| `music3.ogg` | Planet (Celestial) packs |
| `music4.ogg` | the shop |
| `music5.ogg` | boss blinds |

Restart Balatro after an export and pick the pack in Mods → Odeum → Config.
